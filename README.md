# lingguang-skills

个人助理技能库。每个目录是一个独立技能，包含该项目的定制维护指南。

## 技能列表

- **omnibot-customize** — OmniBot（paher1221/OmniBot）个人定制维护：智能体退役、启动默认智能体、设置精简、GitHub Actions 出包流程与踩坑记录。
- **eta-fork-sync** — Eta（paher1221/Eta）个人分支维护：上游同步、补丁集管理、发版流程。

## 用法

把对应技能目录交给支持 Agent Skills 的助手（如 Claude Code、灵光），助手会按 SKILL.md 中的流程执行维护任务。
